# Homebrew Tap for WhiteRoseLK

## How to use

```bash
brew tap WhiteRoseLK/tap
brew install lazyssh
```

Or directly:

```bash
brew install WhiteRoseLK/tap/lazyssh
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| lazyssh | A terminal-based SSH manager inspired by lazydocker and k9s |
